# 📁 Media Assets Directory

This folder is configured for storing your local media assets for GitHub deployment.

---

## 🎥 Avatar Video (`avatar.mp4`)
To display your own personalized AI avatar video in the hero section:
1. Place your video file inside this folder named **`avatar.mp4`** (i.e. `assets/avatar.mp4`) or in the root directory as `avatar.mp4`.
2. The portfolio is pre-configured to detect and play `assets/avatar.mp4` or `avatar.mp4` automatically.
3. If no local file is added, the website automatically falls back to the high-definition futuristic stream and the procedural cyberpunk particle hologram.

**Recommended Video Specifications:**
- Format: `.mp4` (H.264 / AAC) or `.webm`
- Resolution: 1080p (1920x1080) or 4K
- Subject Framing: Avatar centered or positioned slightly to the right half of the frame (so the left remains unobstructed for your title and intro).
- Duration: 10 to 60 seconds (looping or intro statement).
